# Open History logo concepts

Initial macOS app-icon explorations generated on 2026-08-15.

- `chrono-aperture.png` — an open time/archive ring with a timeline marker.
- `timeline-monogram.png` — an abstract continuous-path OH monogram.
- `history-portal.png` — chronological layers opening into a searchable portal.

These are raster concept renders, not final production icon masters. The selected direction should next be simplified into a vector master and tested across the complete macOS icon-size set.
