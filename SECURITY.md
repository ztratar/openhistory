# Security policy

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/ztratar/openhistory/security/advisories/new) instead of opening a public issue.

Include the affected commit, expected impact, and minimal reproduction steps. Do not attach real activity logs, credentials, screenshots, or other private user data. Synthetic fixtures are preferred.

The current `main` branch is the only supported development version. There are no signed production releases yet.
